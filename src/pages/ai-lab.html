Wisconsin Diagnostic Breast Cancer dataset

569 breast masses (212 malignant, 357 benign). Each row holds 30 measurements of cell nuclei taken from a digitised image of a fine-needle aspirate: the mean, standard error and worst value of ten properties such as radius, texture and concave points (Street, Wolberg and Mangasarian, 1993). Licence: CC BY 4.0 (UCI Machine Learning Repository); bundled with scikit-learn.

Why this dataset first: the build environment could not reach the MedMNIST download servers, so a complete, honest experiment was run on data available offline. The chest X-ray pipeline is ready to train on Colab.

Preprocessing: stratified 60/20/20 split into training (341), validation (114) and test (114); standardisation fitted on training data only; test set used once for the final report.

Experiment 2: PneumoniaMNIST chest X-ray CNN Pipeline ready, not yet trained

PneumoniaMNIST (MedMNIST v2; Yang et al., 2023) contains 5,856 paediatric chest X-rays derived from Kermany et al. (2018), resized to 28 × 28, with official splits of 4,708 training, 524 validation and 624 test images. Licence: CC BY 4.0. The task is normal versus pneumonia.

Model architecture

Each conv block: two 3×3 convolutions with batch normalisation and ReLU. Class-weighted cross-entropy (the training set is about 74% pneumonia); model selected on validation AUC; decision threshold set on validation by Youden's J, then applied unchanged to the test set.

Workflow

  1. Download PneumoniaMNIST with the medmnist package.
  2. Scale to [0, 1], z-normalise with training statistics only.
  3. Train 15 epochs with Adam (lr 0.001, batch 128, seed 42).
  4. Report accuracy, precision, sensitivity, specificity, F1, AUC and the confusion matrix on the test set.
  5. Grad-CAM heat maps on the last conv block for correct and incorrect cases.
  6. Error analysis of false negatives first.

Status

The code passes its unit tests (forward pass, one training epoch, probabilities in range, Grad-CAM map shape) on random tensors. Those tests check the code runs; they say nothing about accuracy. No X-ray results or sample images are shown until a real training run is completed on Google Colab with the notebook in the medical-imaging-ai-research repository.

Limitations

  • WDBC is small (569 cases) from one institution in the early 1990s; performance will not transfer unchanged to other populations, labs or imaging equipment.
  • The features were measured from images by an analyst-guided system; the model never sees raw pixels.
  • One random split; the 5-fold cross-validation AUC on the training set is reported alongside to show variability.
  • Permutation importance measures what this model relies on, not biological causation. Correlated features share importance.
  • PneumoniaMNIST images are 28 × 28, far below clinical resolution, and the source set is paediatric.
  • No external validation, no prospective testing and no regulatory review.
